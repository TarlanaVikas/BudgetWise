#  Personal Finance Management Application

## Features
- User Registration and Login
- Add and view income/expenses
- Set and monitor budgets
- Generate monthly/yearly reports
- Backup and restore data

## Installation
1. Install Python 3.x
2. Clone the repository
3. Run: `python main.py`

## How to Use
1. Start the app: `python main.py`
2. Register or login
3. Use dashboard options to:
   - Add income/expenses
   - View reports
   - Set/check budgets
4. Backup: Choose "Backup Data" from main menu

## Example
- Add income: ₹5000, Category: "Salary"
- Add expense: ₹1000, Category: "Food"
- Set monthly budget: ₹3000 for "Food"
- View report to see savings

## Tests
Run all tests: python -m unittest discover tests
